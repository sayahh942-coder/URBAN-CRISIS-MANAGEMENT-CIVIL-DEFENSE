Digital Crisis Management Platform – DCM Platform v2
This version is an offline web-based system for integrated management of disaster risk, KPI monitoring, CRI, projects, budgets, debris, EWS, risk, and corrective actions.

**Key Features:**

* Command Center Dashboard and City Resilience Index (CRI)
* KPI Engine with Optimal / Warning / Critical status levels
* CRI calculation based on the proposed weights: SDGs 20%, Critical Services 30%, Social Contract 25%, Resources 25%
* Scenario Assessment and Risk Reduction Index
* 24-month projects and Gantt charts
* Budget management, Fund Liquidity, and Budget Utilization
* Debris management, Reuse, hazardous waste segregation, and access to critical routes
* EWS: Coverage, Lead Time, and False Alarm Rate
* CAPA/PDCA and corrective actions
* Management reports and browser-based printing/PDF generation
* Automatic saving to LocalStorage
* JSON Import/Export for backup and restoration

**How to Run:**

1. Open the `index.html` file using Chrome or Edge.
2. The system runs without installing a server or any external libraries.
3. Entered data is stored locally in the same browser.

**Note:** KPIs for which the proposal explicitly specified formulas and thresholds have been used as the basis for calculations. For some supplementary indicators where the formula details were not fully available in the extracted text, sample values and editable logic have been used.
